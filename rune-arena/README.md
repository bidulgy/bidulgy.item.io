# 룬 아레나

브라우저에서 실행되는 1인용 2D 보스 러시 게임입니다. 별도 라이브러리나 빌드 과정 없이 `index.html`을 정적 호스팅하면 실행됩니다.

## 게임 흐름

1. 첫 화면에서 게임 시작
2. 검사·수호자·룬술사 중 한 명 선택
3. 보스 8종의 순서를 매 게임 무작위로 섞음
4. 한 보스를 처치하면 회복 후 다음 무작위 보스 생성
5. 중복 없이 8웨이브를 모두 완료하면 승리

## 조작

- `WASD`: 이동
- 짧은 클릭: 휘두르기
- 중간 충전: 검기
- 완전 충전: 돌진 찌르기
- `Shift`: 회피
- `Q`, `E`, `Space`: 캐릭터 스킬

일부 보스는 네온 링 탄환을 발사합니다. 중간 충전 검기로 링을 파괴할 수 있으며, 보스 가까이에서 파괴하면 링이 역폭발해 보스에게 추가 피해를 줍니다.

검사의 돌진이 보스에게 적중하면 2초 동안 검이 꽂혀 플레이어와 보스가 모두 움직이지 못합니다. 이 상태에서도 스킬은 사용할 수 있습니다.

## GitHub Pages

저장소의 Pages 배포 대상을 이 폴더로 지정하거나, 이 폴더의 파일을 Pages용 저장소 루트에 복사하면 됩니다.
