# Rift Bounce

브라우저에서 바로 실행되는 1대1 바운스 액션 게임입니다.

- AI 대전
- 방 코드로 연결하는 온라인 1대1 대전(WebRTC)

## 조작

- 이동: `A`, `D`
- 점프: `W`
- 기본 기술: `E` (기력 소모 없음)
- 2번 기술: `R` (캐릭터별 기력 소모)
- 궁극기: `T` (캐릭터별로 최대 기력의 절반을 초과해 소모)
- 일시정지: `Esc`

`index.html`을 열거나 정적 웹 서버로 실행하세요.

온라인 대전은 두 브라우저가 모두 인터넷에 연결되어 있어야 하며, 일부 제한된 네트워크에서는 WebRTC 연결이 차단될 수 있습니다.
